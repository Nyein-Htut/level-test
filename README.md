# Irene's English — CEFR Diagnostic Test

A fast, modern English proficiency assessment designed to provide an **indicative CEFR level from A1 to C2** in approximately 5 minutes.

Built with a warm **cream & brown** aesthetic, responsive interactions, and a simple, user-friendly experience across desktop and mobile.

## ✨ Features

* **30-question assessment** — Covers all six CEFR levels from A1 to C2.
* **~5-minute test** — Designed to provide a quick indication of English proficiency.
* **CEFR-based results** — Scores are mapped to levels A1, A2, B1, B2, C1, and C2.
* **Mistake review** — Review incorrect answers alongside the correct answers after completing the test.
* **Responsive design** — Optimized for both desktop and mobile devices.
* **Modern UI** — Warm cream, beige, and espresso-inspired visual design with smooth animations.
* **Touch-friendly interactions** — Comfortable tap targets and mobile-optimized feedback.
* **Lightweight & dependency-free** — Built entirely with vanilla HTML, CSS, and JavaScript.

## 🛠️ Built With

* **HTML5** — Semantic page structure
* **CSS3** — Responsive layouts, custom properties, animations, and modern UI styling
* **Vanilla JavaScript (ES6+)** — Quiz logic, scoring, CEFR calculation, and answer review
* **Google Fonts** — Outfit & Plus Jakarta Sans

## 📊 CEFR Scoring

The assessment uses a 30-point scoring system:

| Score |  CEFR  | Description        |
| :---: | :----: | :----------------- |
|  0–5  | **A1** | Beginner           |
|  6–10 | **A2** | Elementary         |
| 11–16 | **B1** | Intermediate       |
| 17–22 | **B2** | Upper-Intermediate |
| 23–27 | **C1** | Advanced           |
| 28–30 | **C2** | Proficient         |

> **Note:** Irene's English is a diagnostic assessment intended to provide an approximate indication of CEFR level. It is not an official CEFR certification or standardized language examination.

## 🚀 Getting Started

No installation, dependencies, or build process are required.

### Clone the repository

```bash
git clone https://github.com/your-username/irenes-english-cefr.git
cd irenes-english-cefr
```

Then open `index.html` in your browser.

You can also use **Live Server** or any static web server for local development.
